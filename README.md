# QuantDesk · 本地 A 股量化工作台

一个跑在你自己电脑上的 A 股研究台。用公开行情做**横截面选股**、**单只回测**、**参数扫描**，把结果沉淀成可回溯的历史记录，再用真实账户做**实盘复盘**。

全程不下单。实盘账户只读取资金、持仓与成交，下单/撤单接口从未被引入。

```
                     ┌──────────────┐
   行情缓存 ─────────▶│  因子截面打分 │──▶ 漏斗过滤 ──▶ 行业分散 ──▶ 候选榜
   (baostock/腾讯)    │  LightGBM    │                              │
                     └──────────────┘                              ▼
                             ▲                              历史后验 T+N
                             │                                     │
                     训练集 + 模型 ◀── 定时管道 ◀──────────────────┘
```

## 核心能力

### 选股

16～18 个个股因子构成横截面快照，经 LightGBM 打分后逐层过滤：

- **因子打分**：动量、波动、量价、RSI、换手、行业动能与行业内相对动量等
- **两种口径**：方向加权基准分（无需训练）／ LightGBM 模型分（预测未来 N 日超额收益）
- **漏斗过滤**：按分数、流动性、涨跌停、ST 等条件逐层筛
- **行业分散**：限制单行业入选数量，避免组合全押一个板块
- **LLM 重排（可选）**：接大模型对候选做语义级复核与理由生成

### 回测

T 日收盘出信号、T+1 开盘成交，尽量贴近真实撮合：

- 佣金（万 2.5，最低 5 元）、印花税 0.05%、过户费 0.001%
- 滑点、涨跌停无法成交、100 股整手约束
- 输出净值曲线、回撤曲线、月度收益热力图、K 线买卖点标注
- 夏普、最大回撤、胜率、盈亏比、超额收益等指标

### 行业研究

- 申万一级 33 类为主、证监会行业补全，覆盖全 A 五千余只
- 行业强度排行、行业内个股相对强弱
- 行业中性化可选三种口径（纯因子／行业中性／行业+市值中性），界面标注取舍

### 实盘复盘

接入东方财富账户（**只读**），把真实交易沉淀成可分析的账本：

- 资金曲线（总资产涨跌 / 剔除出入金的 TWR 双口径）
- 持仓与行业分布、当日盈亏归因
- FIFO 配对计算胜率、盈亏比、持仓天数
- 历史成交、历史委托、资金流水按月切片拉取并落盘
- 委托质量分析：撤单率、滑点
- 行为体检：集中度、单票上限、现金缓冲、亏损集中、费用占比等规则命中
- 交易日记

### 自动化

内置定时器（默认每交易日 18:10）自动跑完整数据链：行情增量 → 快照 → 训练集 → （按需）模型。错过时间窗口会在 4 小时内补跑，失败重试一次。

## 快速开始

### 环境要求

- Python 3.10+（开发环境为 3.13）
- Windows / macOS / Linux，本地运行，仅监听 `127.0.0.1`
- 首次拉全量行情需要耐心（见下方说明）

### 安装

```bash
git clone <你的仓库地址>
cd quant-desk
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 启动

```bash
python app.py
```

浏览器打开 <http://127.0.0.1:8765/>

Windows 用户也可以直接双击 `start.bat`：它会自动检查端口占用、创建虚拟环境、安装依赖并打开浏览器。

### 第一次使用

1. 进入 **数据 → 全 A 名单**，点「预热行情」下载日线。全量约 5500 只，首次约 **60～70 分钟**（6 进程并行），之后日常增量约 8 分钟。
2. 回到 **选股工作台**，首屏会自动跑一次选股（不写入历史记录），确认能看到候选榜。
3. 想固定一组参数并留档，点「重新选股」，这批结果会进入**选股记录**，后续可跟踪 T+5/10/20。

> 行情缓存落在 `data/cache/`，体积可达数百 MB，已被 `.gitignore` 排除。

## 配置说明

所有运行时数据在 `data/` 目录，**不会进入版本库**。仓库只提供示例文件，复制后按需修改。

### 基础配置

`config.json` 已在仓库中（不含任何密钥），可调整费率、初始资金、端口：

```json
{
  "port": 8765,
  "capital": 200000,
  "commission": 0.00025,
  "min_commission": 5,
  "stamp_tax": 0.0005,
  "transfer_fee": 0.00001,
  "slippage": 0.0005,
  "bulk_workers": 6
}
```

### 实盘账户（可选）

1. 复制 `data/emt.example.json` 为 `data/emt.json`
2. 更推荐的做法：启动后进入**实盘复盘 → 账户设置**，在界面里填写资金账号与交易密码
3. 密码由程序用 Fernet 加密后落盘，密钥由本机信息派生——**换机器后需要重新填写**

不配置账户也完全可用：选股、回测、行业研究都不依赖它。

### LLM 重排（可选）

复制 `data/llm.example.json` 为 `data/llm.json`，填入自己的 API Key。支持任何 OpenAI 兼容接口（示例用 DeepSeek）。

不填也能用：候选榜会退回本地规则生成解读。

### 补充数据源（可选）

复制 `data/sources.example.json` 为 `data/sources.json`，填入 Tushare Token 可补充 PE/PB/市值/换手等估值字段。

不填不影响核心功能。

## 工作原理

### 选股链路

```
选股参数
   ↓
resolve_scope        按范围与上限选样本（等间隔取样，避免只取到某一段代码）
   ↓
快照构建             读缓存 → 计算 16~18 个因子 → 截面 z-score
   ↓
中性化（可选）       行业内去均值 / 行业内+市值去均值
   ↓
打分                 LightGBM 模型分 或 方向加权基准分
   ↓
漏斗                 分数、流动性、涨跌停、ST 逐层过滤
   ↓
行业上限             限制单行业入选数
   ↓
LLM 重排（可选）      语义复核 + 理由生成
   ↓
候选榜               落盘到 picks.csv，供后续 T+N 跟踪
```

### 数据流水线

四段可独立执行、也可一键跑完：

1. **行情增量** —— baostock 后复权日线为主，北交所回退腾讯；腾讯快照补当日
2. **快照构建** —— 横截面因子矩阵
3. **训练集构建** —— 多期横截面拼成长表，含 purge（防止标签穿越）
4. **模型训练** —— LightGBM，按时间切分训练/验证

每段都有时效检查，过期才重跑，避免无谓计算。

### 实盘只读边界

`emtlink.py` 只调用查询接口：

- `query_asset_and_position()` 资金与持仓
- `query_orders()` 当日委托
- `query_trades()` 当日成交
- `query_history_trades()` 历史成交
- `query_history_orders()` 历史委托
- `query_funds_flow()` 资金流水

`create_order` / `cancel_order` 从未被 import，界面也无下单入口。这是硬约束，不是配置项。

## 数据与口径

这部分是踩坑记录，也是使用前必须理解的约定。

### 价格口径

- **选股与回测**用**后复权价**（baostock hfq），保证跨除权日的收益连续
- **实盘持仓**用**真实成交价**，两者**不能直接相减**
- 早期版本曾直接相除，得出「宁德时代 -61%」这种纯除权造成的假跌幅，已修正为分开陈述

### 收益口径

- 资金曲线给两种：**总资产涨跌**（含出入金）与 **TWR**（逐日扣掉净转账后连乘）
- 分红、利息算收益，**不算出入金**
- 年化换手在样本不足 5 个交易日时**不外推**（否则三天成交能算出几万百分比）

### 交易口径

- 胜率与盈亏比用 **FIFO 配对**：卖出时配最早买入的成本，费用按份额摊薄
- 费用占比用平仓摊薄后的 `closed_fee`，与 `gross` 保持同口径
- 撤单率 = 已撤 ÷ 总委托；滑点只统计有成交的委托

### 已知限制

- **成本价只有快照能给**：成交明细能拼出流水，但券商摊薄后的成本价只有当日持仓接口返回，所以仍需每日快照
- **分红送转不全**：资金流水能拿到现金分红与红利税，但送转股不产生现金流，只能从持仓数量变化反映
- **训练集天然滞后 2～3 个交易日**：尾部要等未来收益才能打标签，落后超 25 个交易日才需重建
- **行业中性在本样本期是净成本**：行业 β 被一并去掉，实测 RankIC 反而降低；因此默认不用，作为可切口径提供

## 常见问题

**Q：首次预热行情很久，正常吗？**
正常。全市场五千余只、每只上千根日线，串行要 4 小时以上。默认 6 子进程并行压缩到 1 小时左右。并发数不宜再调高，baostock 会互相踢下线。

**Q：提示「行情源被限流」怎么办？**
程序会自动降级用腾讯快照补当日 K 线，并在界面标出。不需要手动干预。

**Q：实盘账户登录失败？**
东财账号连续登录失败会被锁定，因此自动同步**失败不重试**。先在「账户设置 → 测试连接」确认账号密码，再开自动同步。

**Q：换了电脑，实盘密码解不开了？**
密码密钥由本机信息（主机名 + 用户名 + 网卡）派生，换机器必然解不开。重新在「账户设置」里填一次即可。

**Q：终端中文乱码？**
Windows 下 `start.bat` 已设 `chcp 65001`。若手动运行，先执行 `chcp 65001`。

**Q：能把它部署到服务器上吗？**
不建议。这是为本地单机设计的工具，`data/` 里有明文密钥与真实账本，且服务只监听 `127.0.0.1`。若确需远程访问，请自行加反向代理与鉴权，并确保 `data/` 不被暴露。
